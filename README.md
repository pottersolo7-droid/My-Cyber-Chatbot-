## Description
C# Windows Forms Cybersecurity Awareness Chatbot for PROG POE Part 2.

## Features
- Voice Greeting (VoiceGreeting.cs)
- Chatbot UI Form (ChatBotForm.cs)
- ASCII Art (AsciiArt.cs)
- Response Engine (ResponseEngine.cs)
- Audio greetings (greeting.wav)

## How to Run
1. Open CybersecurityBotGUI.sln in Visual Studio 2022
2. Press F5 to build and run
3. Interact with the chatbot
